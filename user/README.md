# Jaxongirman mobile

Expo Router iOS/Android client for Jaxongir Slides. The app contains Supabase email/password auth, recent presentations, credit estimates, context uploads, live generation progress, the editable element canvas, AI edit commands, and private PDF/PowerPoint export with generation and download progress.

Only `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY` belong in `user/.env`. See the [workspace README](../README.md) for setup and backend commands.
